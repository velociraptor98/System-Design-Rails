# PyQt6, and therefore GPL-3.0

The app is built on PyQt6 rather than PySide6. PyQt6 is licensed GPL-3.0-only, so this public repository is licensed GPL-3.0 as well. PySide6 (LGPL) has a near-identical API and would have allowed a permissive licence such as MIT; we chose PyQt6 by preference and accepted the licence constraint.

Switching later is mostly an import rename, but relicensing after outside contributions arrive would need every contributor's consent.
